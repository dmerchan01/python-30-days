# 🐍 Python 30 Days

My daily Python practice, from the basics to more advanced topics, following the
[30 Days of Python](https://github.com/Asabeneh/30-Days-Of-Python) challenge by
[Asabeneh](https://github.com/Asabeneh).

## What I'm doing

- 📖 Every day I study one lesson from the challenge.
- ✍️ I solve the exercises on my own and save my solutions here, one folder per day.
- 📌 I commit and push every day, to build the habit and practice **Git** along the way.

This repo only holds **my own solutions**. The lessons belong to the original repo.

## How to run

Each day is a folder with its own scripts. For example:

```bash
python3 day01/helloworld.py
```
